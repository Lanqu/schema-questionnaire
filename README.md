# Схемные опросники

Объединённые **YSQ-S3R** (Young Schema Questionnaire, краткая форма, 3-я редакция) и **SMI v1.1** (Schema Mode Inventory) в виде одностраничного веб-инструмента для самооценки в рамках схема-терапии.

**Живая версия:** https://schema-questionnaire.surge.sh

## Что это

214 вопросов (90 YSQ + 124 SMI) с подсчётом результатов на стороне клиента и клинической интерпретацией. Весь текст на русском.

**Возможности опросника:**
- Вкладки с отслеживанием прогресса по каждой
- Клик по тексту вопроса показывает, что означает оценка 6 для этого пункта
- Клавиатура: наведи курсор на вопрос и нажми 1-6
- Автосохранение в localStorage, автоскролл к следующему неотвеченному
- Поделиться результатом через URL (ответы кодируются во фрагменте после `#`)

**Результаты:**
- YSQ: 18 схем, сгруппированных по 5 доменам, отсортированы по баллу, с процентом и средним
- SMI: 14 режимов отсортированы по клинической значимости и по категории
- Реверсные режимы (Здоровый Ребёнок, Здоровый Взрослый) корректно обработаны в визуализации и сортировке
- Клик по строке схемы/режима раскрывает: клиническое описание, значение уровня, разбивку по пунктам
- Клик по пункту в разбивке прыгает к вопросу — можно изменить ответ
- Плавающая кнопка "к результатам" возвращает обратно после правки

## Как собрать и задеплоить

```bash
python src/build_form.py    # генерирует dist/index.html
cd dist && npx surge .      # деплой на schema-questionnaire.surge.sh
```

```
src/

  scoring/                   # JS-модули скоринга (источник истины)

    smi_scoring.js
  data/                      # тексты вопросов, подсказки, клинические описания
    questions.json
    interpretations.json
tests/                       # браузерные тесты скоринга
dist/                        # собранный артефакт для деплоя
```

## Методология скоринга

**YSQ-S3R:** Каждая из 18 схем имеет 5 вопросов с оценкой 1-6. Формула процента: `(сумма - 5) / 25 * 100`. Пять уровней — от "низкий" до "высокий". Схемы агрегируются в 5 доменов.

**SMI v1.1:** 14 режимов, по 4-10 пунктов в каждом. 15 пунктов используются в двух режимах одновременно (по мануалу SMI). Нормативные пороги дают 6 уровней. CC (Здоровый Ребёнок) и HA (Здоровый Взрослый) реверсные: высокий сырой балл = здоровое состояние.

Скоринг проверен против формул из эталонных Excel-таблиц.
